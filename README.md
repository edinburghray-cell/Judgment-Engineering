# Judgment Engineering

Research on preserving human reasoning as organizational memory for AI-assisted decision making.

## Research Question

How can organizations preserve, reuse, and improve human judgment as organizational memory instead of preserving only outcomes?

## Current Work

- White Paper
- Conceptual Framework
- Four Research Simulations
- Visual Illustrations
- System Architecture Diagrams

## Vision

To help AI systems and engineering organizations preserve decision rationale, accelerate onboarding, improve consistency, and enable continuous organizational learning.

## Status

This repository documents the ongoing development of the Judgment Engineering research framework.
